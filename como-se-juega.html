Regla de oro

Cada sesión debe empezar y terminar en la Base. Si no se vuelve, se registran consecuencias.

La idea en una frase

Tú eliges el objetivo y el grupo; el mundo responde. El progreso real es el conocimiento compartido.

Ciclo de una expedición

  1. Se propone un objetivo (lugar + intención).
  2. Se arma la party (ideal 4–6).
  3. Se sale desde la Base, se explora, se decide riesgo.
  4. Se vuelve (o se asumen consecuencias).
  5. Se publica reporte + mapa actualizado.

Qué se espera del jugador

  • Traer equipo, plan y criterio.
  • Colaborar y decidir con rapidez bajo presión.
  • Leer reportes cuando sea relevante.
  • Registrar hallazgos (aunque la sesión “salga mal”).

El mundo no está balanceado

  • Habrá cosas que no puedes pelear todavía.
  • Retirarse a tiempo es una victoria.
  • Si fuerzas una pelea perdida, el mundo no se ajustará.

El DM

  • No dirige una trama principal.
  • Aplica reglas y consecuencias coherentes.
  • No protege a los personajes, pero tampoco “castiga” gratis.

Regla práctica de cierre

Si la sesión se acerca al final y aún están lejos, el grupo decide: volver ahora o arriesgarse. Lo importante es que el estado final quede claro en el Registro.
